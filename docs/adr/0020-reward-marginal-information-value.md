# ADR-0020: Reward marginal information value, not volume

**Status:** Accepted
**Accepted:** 2026-08-17
**Date:** 2026-08-17
**Supersedes:** none
**Superseded by:** none

## Context

If points scale with submission count, a leaderboard is an instruction to farm the nearest
store with the fewest items, and contributors will follow it precisely.

Coverage would then concentrate where it is already dense, while the empty and stale cells that
actually block index publication stay empty.

The value of an observation is computable: it depends on how stale or sparse the target cell already
is.

## Decision

Reward tracks how much the corpus did not already know:

```
value = base
      * staleness_factor(branch, product)
      * scarcity_factor(branch, product)
      * bounty_multiplier(active bounties)
```

`bounties` targets branch, product or category with a multiplier and an expiry, generated by
scheduled sweeps for empty and stale cells, or by an operator for a campaign.

Overlapping bounties do not stack multiplicatively; the highest single multiplier applies.

Leaderboards rank on value contributed, not submission count, and are windowed rather than
all-time.

## Consequences

The leaderboard becomes a coverage-optimisation mechanism instead of a noise
generator.

Bounties are the main lever available when index coverage falls below its publication floor.

Bounty-directed collection distorts the sample, which is disclosed as a validity threat in ADR-0080
rather than hidden. Bounties must not be so concentrated that they worsen it materially.

Reward is not predictable in advance from the contributor's point of view, which needs clear
in-app explanation or it reads as arbitrary.

## Alternatives considered

**Flat per-submission reward.** Rejected. Produces exactly the concentration the
system cannot afford.

**Per-observation reward.** Rejected. Rewards long receipts from one shop over targeted coverage.

**Operator-only bounties.** Rejected. Does not react fast enough to staleness, which changes daily
under high inflation.

## Revisit trigger

Measured contributor concentration or geographic skew worsens despite bounties, indicating
the incentive is not the binding constraint.
